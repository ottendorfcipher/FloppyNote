# FloppyNote

A lightweight, single-file text editor that fits on a floppy disk.

Weighing in at 288,921 bytes, you can fit 5 of these `.html` files on a single 1.44 MB floppy disk. And not a single legacy system can run it. Entirely vibe coded. With love.
